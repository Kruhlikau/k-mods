# 붙임 메모

자주 쓰는 문구를 입력창 위에 색깔 칩으로 붙여 두고, 한 번 클릭하면 복사, 두 번 클릭하면 입력창에 넣어요.

## 설치

```
/plugin marketplace add SeongGwangJu/k-mods
/plugin install sticky-memo@k-mods
```

## 쓰는 법

입력창 위 막대에 메모가 색깔 칩으로 붙어요. 처음에는 `+ 붙임 메모` 칩 하나만 보여요.

| 하고 싶은 일 | 방법 |
| --- | --- |
| 메모 내용 복사 | 칩을 **한 번 클릭**. 칩에 `✓`가 잠깐 떠요 |
| 입력창에 넣기 | 칩을 **두 번 클릭**. 커서 자리에 들어가고, 보내지는 않아요 |
| 새 메모 | `+` 클릭 → 입력창에 내용을 쓰고 Enter |
| 메모 고치기 | `✎` 클릭(수정 모드) → 칩 클릭 → 입력창에서 고치고 Enter |
| 막대 숨기기·보이기 | `/sticky` (작업 중에도 돼요) |

### 수정 모드

`✎`를 누르면 수정 모드가 돼요. 이때 칩을 누르면 복사나 넣기 대신 그 메모가 펼쳐져요.

- **내용**은 입력창으로 옮겨져요. 여러 줄도 평소처럼 고치고, Enter나 `[저장]`을 누르면 저장돼요. 원래 입력창에 쓰던 글은 보관했다가 돌려줘요.
- **제목**은 막대의 제목 칸에서 바꾸고 Enter. 비우면 내용 첫 줄이 칩 이름이 돼요.
- **색**은 파스텔 8색 중에서 고르거나 `#` 칸에 `#RRGGBB`로 직접 적어요. 누르는 즉시 저장돼요.
- `[취소]`는 내용 수정만 버리고, `[삭제]`는 두 번 눌러야 지워져요.
- `완료`를 누르면 평소 모드로 돌아가요.

`+`로 새 메모를 만들 때 입력창에 쓰던 글이 있으면 그 글로 시작해요. 방금 쓴 프롬프트를 그대로 메모로 남길 수 있어요. 저장한 뒤에도 입력창 글은 그대로 남아요.

칩이 한 줄에 다 들어가지 않으면 `N개 더`로 묶여요. 누르면 전부 펼쳐지고, `접기`로 다시 접혀요.

메모는 모든 폴더에서 똑같이 보이고, 세션을 끝내도 남아요. 세션을 여러 개 띄워 두면 4초 안에 서로 맞춰져요.

### 마우스 클릭이 안 될 때

칩 클릭은 Claude Code의 fullscreen 화면에서 받아요(설정 파일의 `"tui": "fullscreen"`). fullscreen이 아니거나 데스크톱 앱이면 칩이 키보드로 누를 수 있는 버튼으로 바뀌어요. `ctrl+x tab`으로 막대에 들어가 Tab으로 칩을 고르고 Enter를 누르면 복사, 빠르게 두 번 누르면 넣기예요.

## 설정

없어요. 색은 메모마다 수정 모드에서 골라요.

## 어떻게 동작하나요

- **세션이 시작할 때**: `/sticky` 명령을 등록하고, 이 mod 전용 저장소(`$.store`)에서 메모를 불러와요. 그 뒤 4초마다 저장소를 다시 읽어 다른 세션에서 바꾼 메모를 반영해요.
- **입력창 위 막대를 그릴 때**: 다른 mod가 그린 줄은 그대로 두고 그 아래에 칩 줄을 더해요. 설문이 떠 있으면 비켜 줘요.
- **칩은 마우스 신호를 직접 받는 요소(`Client`)로 그려요.** Claude Code의 일반 버튼은 더블클릭하면 두 번째 클릭을 넘겨주지 않고, 그 자리 글자를 골라 클립보드에 복사해 버리기 때문이에요.
- **한 번 클릭은 0.4초 기다렸다가 복사해요.** 그 안에 한 번 더 누르면 더블클릭으로 보고 입력창에 넣어요. 바로 복사하면 더블클릭할 때마다 클립보드가 바뀌어서, 메모를 넣고 미리 복사해 둔 다른 글을 붙여넣는 흐름이 깨져요.
- **수정 모드에서 Enter를 누르면** 그 글을 모델에 보내지 않고 메모로 저장해요(`prompt.submit`). 대화창에 `Prompt dropped by a hook: '…' 메모를 저장했어요` 한 줄이 남아요. 사람이 입력창에서 친 Enter만 가로채고, 작업 알림이나 다른 세션의 메시지는 그대로 보내요.

## 권한 (이 mod가 내 컴퓨터에서 하는 일)

- 이 mod 전용 저장소(`~/.claude/plugins/store/` 아래 JSON 파일)에 메모를 저장해요.
- 칩을 한 번 클릭했을 때만 클립보드에 메모 내용을 써요.
- 입력창 글을 읽고 바꿔요. 더블클릭으로 넣을 때와, 수정 모드에서 내용을 옮기고 쓰던 글을 돌려줄 때뿐이에요.
- 네트워크, 일반 파일, 프로그램 실행, 모델 호출은 없어요.

## 한계

- 마우스 클릭은 fullscreen 화면에서만 돼요. 그 밖에서는 키보드로 써요.
- 붙여넣은 긴 글은 입력창에 `[Pasted text #1 +14 lines]`처럼 접혀 보여요. 이 상태에서는 `[저장]` 버튼으로 저장할 수 없고(Claude Code가 접힌 글을 펼쳐 주지 않아요), Enter로 저장해야 해요. 수정을 시작할 때 입력창에 붙여넣은 글이 남아 있으면 먼저 보내거나 지워 달라고 안내해요.
- 화면 우측 상단처럼 고정된 자리는 Claude Code에 없어서 입력창 위 막대에만 붙어요.
- 여러 기기(예: 맥북과 맥미니) 사이에는 메모가 동기화되지 않아요.
